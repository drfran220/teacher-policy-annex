# Teacher Policy Document Annex (France & China, 2000–2023)

This repository contains the file names (titles only) of teacher policy documents issued in France and China between 2000 and 2023. The data is intended as a transparent annex to support research findings.

📄 **Annex File**:  
`Annex_Teacher_Policy_France_China_2000_2023.xlsx`

🔒 Note: This repository only includes file titles for academic review. Full policy texts are not redistributed.
