# Teacher Policy Document Annex (France & China, 2000–2023)

This repository contains the file names of teacher policy documents issued in France and China between 2000 and 2023. The data is intended as a transparent annex to support research findings.

📄 **Annex File**:  
`Annex_Teacher_Policy_France_China_2000_2023.xlsx`

🔒 Note: This dataset contains the metadata for the Chinese and French teacher policy documents analysed in the study ‘Constructing the “Reflective” and “Difficult” Teacher: Pragmatic Policy Discourses in China and France (2000–2023)’. The metadata file was prepared by the author and provides information used to identify and organise the policy corpus, including national context, document title, year, document type, issuing institution and thematic category.
